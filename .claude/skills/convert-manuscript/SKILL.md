# Convert a manuscript to BML

Grammar: `bml-spec-v06.md` (read §2–§7 once). Verify with
`deno task bml check <slug>` — zero diagnostics is the floor, not the goal.
The goal is the house shape below. `books/a-christmas-carol/manuscript.md`
is the reference example; copy its structure.

## Output shape, in order

```
%% FRONT MATTER
{matter: half-title}   {title}
{matter: title-page}   {title} {subtitle}? {author} {year}  (+ {publisher} {publisher-location} if known)
                       {year} = original publication year; the PG header rarely has it — use what you know, note it in your report
{matter: copyright}    {copyright-line} "This text is in the public domain."
                       {rights} "Sourced from Project Gutenberg eBook #N, produced by <credits>. No rights reserved."
                       {edition} "First edition, <year>"
{matter: toc}          {title} on its own line, text `Contents`, then `%% auto-generated by renderer`, no entries
{matter: dedication}?  lines joined with `\`
{matter: epigraph}?    {epigraph} lines joined with `\` — {attribution} "— Name"
{matter: preface|introduction|foreword}?  {title} + prose
%% BODY MATTER
{chapter: <slug>} per chapter, {title} only if the source has a real title
  {dropcap} before the FIRST paragraph of EVERY chapter (and preface/intro)
  {break} for every source section rule (`---`, `* * *`, extra blank block)
%% BACK MATTER
{matter: appendix|notes}? from source
{matter: colophon}     {typeface} {paper} {binding} {printer}
                       {printer} = "Text from Project Gutenberg eBook #N (gutenberg.org/ebooks/N), a public-domain transcription of the <year> edition."
```

Half-title, title-page, copyright, toc, colophon are always present. Provenance
lives in `{rights}`/`{printer}`, never in `%%` comments.

## Source → BML mapping

| In the source | Write |
|---|---|
| Header through `*** START OF …***`, footer from `*** END OF …***` (or from the first license paragraph if the marker is missing) | delete |
| Source table of contents | delete (renderer generates it) |
| Roman-numeral / "CHAPTER III" heading with no title | `{chapter: three}` — slug is the spelled-out word or the source's own term (`stave-1`) |
| Heading with a title | `{chapter: two-word-slug}` + `{title}` |
| `_word_` or ALL-CAPS emphasis | `{em}word{/em}` (leave capitalised proper names alone) |
| `[Illustration: Caption]` | `{illustration: caption-slug \| placement: full-page}` + caption line; file goes in `images/<slug>.<ext>` |
| `[1]` … footnote text at chapter end | `word{footnote: slug}` inline, `{note: slug}` block after the paragraph |
| Poem / verse / address | one line per line, `\` at end of each but the last |
| Paragraph wrapped at ~70 cols | keep the wrapping as-is; blank line = paragraph |
| Lines starting `-`, digit-dot, `%%`, `{` in prose | escape with leading `\` (§2.8) |

Slugs: lowercase, hyphens, ≤3 words, unique across the book. Curly quotes and
em dashes from the source stay; don't normalise to ASCII.

## Finish

1. `deno task bml check <slug>` → 0 diagnostics.
2. `grep -c '^{chapter' manuscript.md` equals the number of chapter headings actually present in the source (not the source TOC);
   `grep -c '^{dropcap}'` equals chapters + prose front-matter sections.
3. `grep -n 'Gutenberg\|\*\*\* \|\[Illustration' manuscript.md` shows only the `{rights}` and `{printer}` lines.
4. If `metadata.json` is missing, copy `books/a-christmas-carol/metadata.json` — styling is a separate job.
