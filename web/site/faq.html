Questions

Is Wynkyn free?
Yes. It is open source under the MIT license, with no tiers and no trial. Everything that runs on your own device is free and will stay free. A paid option to keep books in the cloud, synced between devices, is planned; it will never be needed to use the app.
Do I need an account?
No. Open the editor and start writing. There is nothing to sign up for and nothing is stored on the site.
Where are my files?
In Chrome or Edge, Wynkyn opens a folder on your own computer (you choose where) and works on the files in it: a book is a folder with manuscript.md, metadata.json and an images folder. Edit them with any other tool and the app picks up the change. In other browsers, books live in the browser's own storage, which the browser may clear, so download the books you want to keep as a zip from the book menu.
Which browsers work?
Chrome and Edge give the full experience: they can open your own folder and their print dialog produces exact pages. Firefox and Safari run the app with books kept in browser storage, and printing from them may differ slightly. Brave works like Chrome once its file-system permission is turned on.
Can I print at a copy shop?
Yes. Print to PDF from the editor and take the file in. The pages are already arranged on the sheets, so once you fold and nest them the signatures read in order. Tell the shop the sheet size you chose and whether to print both sides. If the shop prints single-sided only, the page setup has an option to print the backs separately.
Can I bring in a manuscript I already have?
Yes. The editor imports Word, EPUB, plain text, Markdown and HTML, finds the chapters, and marks anything it was unsure about for you to check. From Google Docs, use File › Download › Microsoft Word and import that.
Does it make e-books?
Yes. Export EPUB writes an EPUB 3 from the same manuscript, with the same styling, for e-readers and e-book stores. The text reflows to fit whatever screen it is read on.
How do I send feedback or report a problem?
Open an issue on the project's GitHub page. You will need a free GitHub account. Say what you were doing, what you expected and what happened instead, and which browser you use. A screenshot helps. Please leave your manuscript out unless you are happy for it to be public, since issues can be read by anyone.
Can I ask for a feature?
Yes, the same way. Open an issue and describe the book you are trying to make and what is in the way. First look through the existing issues in case someone has asked already; add your voice there if so.
